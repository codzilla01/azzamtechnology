# Azzam Technology

واجهة عربية وإنجليزية لمتجر أجهزة الكمبيوتر والشاشات واللابتوبات، مبنية بـHTML وCSS وJavaScript. تتضمن البحث والفلترة، والمفضلة والمقارنة والسلة، وتجميع PC، وإرسال تفاصيل الطلب عبر واتساب.

> **المتجر ما زال نموذجاً وليس متجراً جاهزاً للإنتاج.** المنتجات والسلة والمفضلة وغيرها محفوظة في `localStorage` لكل متصفح؛ ليست بيانات مشتركة ولا توجد قاعدة منتجات أو خدمة دفع أو إدارة طلبات على الخادم، ولا تنتقل المنتجات من جهاز الإدارة إلى أجهزة العملاء تلقائياً.

> **تنبيه أمني:** تم إلغاء شاشة تسجيل الدخول والاعتماد على الدخول عبر **الضغط المطول على شعار المتجر (3 ثوانٍ)**. مسار `/admin.html` يفتح مباشرة دون اسم مستخدم أو كلمة مرور، لذا لا تعتمد على هذا الوضع لحماية بيانات حساسة على الإنترنت العام. كما كان رمز بوت Telegram مكشوفاً في نسخة سابقة من الواجهة وتاريخ Git؛ يجب **إلغاء الرمز القديم من BotFather** لأن حذفه من الملفات لا يلغيه.

## التشغيل محلياً والدخول إلى لوحة الإدارة

يتطلب Node.js **22.x**:

```bash
npm ci
HOST=127.0.0.1 npm start
```

افتح `http://localhost:8000`، وللدخول إلى لوحة الإدارة **اضغط مطولاً على شعار Azzam Technology في أعلى المتجر لمدة 3 ثوانٍ** حتى يكتمل شريط التقدم ويتم فتح `/admin.html` مباشرة.

لا يُستخدم `python -m http.server` أو فتح الملفات مباشرة لتشغيل الموقع لأن الخادم المرفق (`server.js`) يقتصر على عرض الملفات العامة المسموح بها ويعيد توجيه `/admin` إلى `/admin.html` عبر نقطة `/api/admin`.

## النشر على Vercel

يقوم `vercel.json` بتنفيذ `npm run build` لإنتاج مجلد `public/` الذي يحتوي على الملفات العامة للمتجر فقط، ويوجه `/admin` و`/admin.html` إلى الوظيفة الخادمية `/api/admin` التي تقدم `private/admin.html` مباشرة دون الحاجة إلى Redis أو متغيرات بيئة إضافية.

## اللغات وبيانات المنتجات

- العربية هي اللغة الافتراضية. استخدم زر `EN` / `عربي` في المتجر أو المساعد أو الإدارة للتبديل؛ يتغير الاتجاه تلقائياً، ويُحفظ الاختيار في `localStorage` ويُزامَن بين تبويبات الموقع.
- تترجم الواجهة والرسائل المدمجة محلياً في `i18n.js`. إجابات المساعد المخصصة التي يكتبها المسؤول تظل كما أُدخلت ولا تُترجم تلقائياً.
- يمكن إدخال اسم المنتج ووصفه ومواصفاته بالإنجليزية اختيارياً؛ تتطلب كل مواصفة مترجمة اسماً وقيمة أصليين. عند غياب الترجمة يُعرض الأصل، ولا تتغير المنتجات الموجودة تلقائياً. يشمل البحث البيانات الأصلية والترجمات، وتُضمَّن الترجمات في التصدير والاستيراد.
- مسح بيانات المتصفح يزيل تفضيل اللغة وبيانات المتجر المحلية. عند عدم وجود منتجات يعرض المتجر حالات فارغة بدلاً من أسعار أو منتجات وهمية. الخطوط والأيقونات مستضافة محلياً داخل `assets/vendor` مع تراخيصها.

## الاختبارات

```bash
npm ci
npm run test:auth          # اختبارات الخادم وبناء الحزمة العامة والوصول المباشر للإدارة
npx playwright install chromium
npm test                   # اختبارات الواجهة والضغط المطول واللغات والتسوق
npm run build              # إنشاء حزمة الملفات العامة للنشر
```
