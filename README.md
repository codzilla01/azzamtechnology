# Azzam Technology

متجر إلكتروني ثنائي اللغة (العربية والإنجليزية) لأجهزة الكمبيوتر والشاشات واللابتوبات، مبني بـHTML وCSS وJavaScript مع واجهة برمجية خادمية (Node.js / Vercel Serverless) وقاعدة بيانات **Supabase PostgreSQL** (مع وضع تخزين محلي تلقائي `FileStore` للتطوير والاختبارات).

## المزايا الرئيسية

- **وصول مباشر للوحة التحكم عبر الشعار**: الدخول عبر **الضغط المطول على شعار المتجر (3 ثوانٍ)** لفتح `/admin.html` مباشرة دون صفحة تسجيل دخول.
- **كتالوج مشترك عبر الأجهزة**: إدارة المنتجات (اللابتوبات، الشاشات، أجهزة PC المجمعة، وقطع التجميع)، المخزون، الأسعار قبل/بعد الخصم، الكوبونات، رسائل المساعد الذكي، وإعدادات المتجر عبر قاعدة البيانات.
- **ضغط تلقائي للصور + روابط خارجية**: ضغط الصور المرفوعة تلقائياً في المتصفح (WebP/JPEG) أو استخدام روابط صور خارجية `http/https`.
- **سلة التسوق والطلب**: التحقق من توفر المخزون وكود الخصم على الخادم، نموذج بيانات العميل والشحن، تسجيل الطلب في قاعدة البيانات وخصم المخزون، وإرسال ملخص الطلب عبر واتساب.

## التشغيل محلياً

يتطلب Node.js **22.x**:

```bash
npm ci
HOST=127.0.0.1 npm start
```

افتح `http://localhost:8000`، وللدخول إلى لوحة الإدارة **اضغط مطولاً على شعار Azzam Technology في أعلى المتجر لمدة 3 ثوانٍ** ليتم فتح `/admin.html` مباشرة.

## النشر على Vercel + Supabase

1. أنشئ مشروعاً جديداً على [Supabase](https://supabase.com) وشغّل ملف `supabase/schema.sql` داخل **SQL Editor**.
2. في إعدادات مشروع Vercel أضف متغيرات البيئة التالية (انظر `.env.example`):
   - `SUPABASE_URL`: رابط مشروع Supabase.
   - `SUPABASE_SERVICE_ROLE_KEY`: مفتاح `service_role` السري (للاستخدام الخادمي فقط).
3. يقوم `vercel.json` بتنفيذ `npm run build` لإنتاج مجلد `public/` للملفات العامة فقط، بينما تُدار طلبات `/admin.html` و`/api/*` عبر الخادم.

> **ملاحظة أمنية:** تم إزالة شاشة تسجيل الدخول بناءً على طلب مالك المتجر؛ مسار `/admin.html` وواجهات `/api/admin/*` تفتح مباشرة دون مصادقة. كما يجب إلغاء أي رمز Telegram قديم إن كان مكشوفاً في تاريخ Git السابق.

## الاختبارات

```bash
npm ci
npm run test:auth          # اختبارات الخادم والتحقق والمخزون والطلبات والوصول المباشر وبناء الحزمة العامة
npx playwright install chromium
npm test                   # اختبارات المتصفح الكاملة (الدخول، المتجر، السلة، الكوبون، الطلب، اللغات)
npm run build              # إنشاء حزمة الملفات العامة للنشر
```
